📋 부적합 통보서 작성 (수기입력)

성적서에 연결하지 않고 직접 입력해서 발행해 — 이 시스템 도입 전 회사 로컬에만 있던 과거 불량 기록을 지금 통보서로 남기고 싶을 때 써. 이미 검사입력이 돼 있는 건은 해당 성적서 상세 화면의 "부적합 통보서" 버튼을 쓰는 게 더 편해. 자재를 여러 개 담으면 자재마다 통보서가 각각 발행돼.

🔍 입고·검사 이력에서 불러오기 (선택 — 검색 결과를 클릭하면 아래 목록에 추가돼. 다시 클릭하면 목록에서 빠져. 여러 개 골라도 돼)

조건을 하나 이상 입력하면 자동으로 찾아줘 (검색 버튼을 눌러도 돼)

📦 자재 직접 추가 (검색에 없는 과거 자재는 여기서 입력)

📦 발행 대상 자재 목록

자재를 여러 개 담으면 자재마다 통보서가 각각 발행돼. LOT수량·시료수·불량수는 자재(로트)마다 다를 수 있어서 행별로 따로 입력해. 불량 내용·사진은 아래 "통보서 내용"에 공통으로 1번만 입력하면 모든 통보서에 똑같이 들어가 — 자재마다 불량 내용이 다르면 이 화면을 나눠서 여러 번 작성해줘.

아직 추가된 자재가 없어. 위 검색 결과를 클릭하거나 직접 입력해서 추가해줘.
