입고검사 성적서 시스템 — 1단계
================================

[처음 1회만]
1. 이 폴더(iqc-app)를 PC 아무 곳에나 저장
2. 명령 프롬프트(cmd)를 열고 이 폴더로 이동
     cd 경로\iqc-app
3. 필요한 패키지 설치
     pip install flask openpyxl pillow
4. 규격 데이터 심기 (602106P103 예시 1건 등록됨)
     python seed_data.py

[실행할 때마다]
5. 서버 실행
     python app.py
   "Running on all addresses (0.0.0.0)" 문구가 뜨면 정상

6. 같은 PC에서 확인: 브라우저에 http://127.0.0.1:5000
   태블릿에서 접속: http://<이 PC의 IP주소>:5000
     - PC의 IP 확인: cmd에서 ipconfig 실행 → "IPv4 주소" 확인
     - 태블릿과 PC가 같은 와이파이(공유기)에 연결돼 있어야 함
     - 회사 와이파이가 기기 간 통신을 막아둔 경우 접속 안 될 수 있음(그땐 확인 필요)

[로그인 / 계정]
서버를 처음 실행하면 전체 권한을 가진 기본 계정이 자동으로 만들어집니다.
  아이디: admin
  비밀번호: admin1234
반드시 로그인 후 우측 상단 "비밀번호 변경"에서 바꾸고, "관리" 메뉴 → "계정 관리"에서
필요한 계정들을 만들어주세요.

역할은 고정돼 있지 않고, 계정마다 아래 권한을 하나하나 체크해서 필요한 것만 부여합니다.
  - 입고 리스트: 입고 건 등록
  - 규격 관리: 규격 등록/수정/삭제(개별·일괄·그룹 전부)
  - 검사 입력: 검사 입력, 본인이 입력한 성적서만 수정
  - 타인 성적서도 수정: 이 권한이 있으면 남이 입력한 성적서도 수정 가능
  - 승인·반려·특채: 결정권자 승인 화면 접근
  - 출력: 승인된 성적서를 xlsx/PDF로 출력
  - 계정 관리: 계정 생성/삭제/권한부여/비밀번호 확인.
    이 권한이 있는 계정은 10분 동안 화면을 안 만지면 자동으로 로그아웃됩니다(보안 목적).
  - 활동 로그 열람

"계정 관리" 권한이 없는 계정은 하루(24시간) 동안 로그인이 유지되니 태블릿마다
매번 로그인할 필요는 없습니다(계정관리 권한이 있는 계정만 10분 무동작 자동
로그아웃이 우선 적용됩니다).

비밀번호는 평문으로 저장됩니다(내부 전용 시스템 특성상). "계정 관리" 화면에서
계정관리 권한을 가진 사람이 언제든 각 계정의 현재 비밀번호를 확인·초기화할 수
있습니다. 단, 본인 계정 비밀번호는 화면에서 가려집니다(다른 관리자가 봐야 함).

[자재 그룹(조립품)]
입고는 조립품 하나로 들어오지만 검사할 땐 분해해서 부품마다 따로 측정하는 자재를 위한 기능.
상단 메뉴 "자재 그룹"에서 조립품 자재번호를 만들고, 부품(각자 규격이 먼저 등록돼 있어야 함)들을
순서대로 추가하면 됨. 입고 리스트엔 조립품 자재번호로 한 줄만 등록하면 되고, 검사 입력 화면엔
부품들이 순서대로 이어져서 나옴(부품이 바뀌는 지점마다 구분 표시). 성적서는 부품마다 시트가
나뉜 xlsx 파일 1개로 나가고 PDF도 그 순서 그대로 여러 페이지로 이어짐.

[활동 로그 / 자동 백업]
성적서 등록·수정, 규격 등록·수정·삭제, 입고 리스트 등록, 승인/반려, 계정 관리 등
데이터가 새로 생기거나 바뀔 때마다 자동으로:
  1. 상단 메뉴 "활동 로그"(admin 전용)에서 조회 가능한 기록이 남고
  2. backups/ 폴더에 그 시점의 iqc.db 전체가 통째로 복사·저장되고
  3. backups/README.txt에 사람이 읽을 수 있는 상세 로그 한 줄이 추가됩니다
     (예: "[2026-08-19 19:06:56] 사용자: admin(최고관리자) | 액션: 입고 리스트
      등록 | 대상: intake | 상세: 1건(602106P103) | 백업파일: iqc_..._2.db")
문제가 생기면 backups/README.txt에서 원인이 된 시점을 찾고, 그 옆에 적힌
백업파일(iqc_YYYYMMDD_HHMMSS_번호.db)을 iqc.db로 이름 바꿔서 복원하면 됩니다.
주의: 변경이 잦으면 backups 폴더가 계속 커지니, 가끔 오래된 백업은 직접 정리해주세요.

[새 자재 추가하는 법 - 지금은 코드로]
seed_data.py를 참고해서 같은 형식으로 자재/항목을 추가하고 다시 실행하면 됩니다.
(다음 단계에서 "규격 등록 화면"을 만들면 코드 없이 웹에서 입력 가능해집니다)

[폴더 구성]
  app.py            - 서버 본체
  database.py       - DB 관리
  judge.py          - 판정 로직 (규격 대조)
  report_builder.py - 성적서 xlsx/PDF 생성
  seed_data.py       - 초기 규격 데이터
  template_form.xlsx - 빈 성적서 양식
  templates/input.html - 태블릿 입력 화면
  iqc.db            - (실행 후 자동 생성) 데이터베이스
  성적서 발행/       - (실행 후 자동 생성) 완성된 성적서 저장 위치 — 생성날짜별 폴더 안에
                      "YYMMDD_업체명_자재번호_제품명.pdf/.xlsx" 형식으로 저장됨
