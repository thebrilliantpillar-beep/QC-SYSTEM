입고검사 성적서 시스템 — 1단계
================================

[처음 1회만]
1. 이 폴더(iqc-app)를 PC 아무 곳에나 저장
2. 명령 프롬프트(cmd)를 열고 이 폴더로 이동
     cd 경로\iqc-app
3. 필요한 패키지 설치
     pip install flask openpyxl pillow
   (자재 데이터는 서버 실행 후 웹의 "자재" 메뉴에서 직접 등록합니다 — 아래 참고)

[실행할 때마다]
4. 서버 실행
     python app.py
   "Running on all addresses (0.0.0.0)" 문구가 뜨면 정상

5. 같은 PC에서 확인: 브라우저에 http://127.0.0.1:5000
   태블릿에서 접속: http://<이 PC의 IP주소>:5000
     - PC의 IP 확인: cmd에서 ipconfig 실행 → "IPv4 주소" 확인
     - 태블릿과 PC가 같은 와이파이(공유기)에 연결돼 있어야 함
     - 회사 와이파이가 기기 간 통신을 막아둔 경우 접속 안 될 수 있음(그땐 확인 필요)

[로그인 / 계정]
서버를 처음 실행하면 전체 권한을 가진 기본 계정이 자동으로 만들어집니다.
  아이디: admin
  비밀번호: admin1234
반드시 로그인 후 우측 상단 "비밀번호 변경"에서 바꾸고, "설정" 메뉴 → "계정 관리"에서
필요한 계정들을 만들어주세요.

[권한 부여 방법]
역할은 고정돼 있지 않습니다. 계정마다 필요한 기능만 하나하나 체크해서 부여합니다.
"설정 → 계정 관리"에서 계정을 클릭하면 그 계정의 "상세·권한 설정" 페이지가 열리고,
거기서 기능별 권한을 그룹 단위로 켜고 끕니다. (새 계정을 만들면 바로 이 상세페이지로
넘어가니 거기서 권한을 정해주면 됩니다.)

권한은 기능별로 세분화돼 있습니다:
  [입고]  입고 리스트 등록·관리
  [검사]  검사 입력 / 타인 성적서도 수정 / 검사 이력 열람 / 검사 이력 삭제 /
          불량 이력 열람 / 부적합 통보서 작성 / 부적합 통보서 확인·발송 / 반품 처리
  [승인]  승인·반려·특채·불합격 확정 / 결정 회수
  [출력]  성적서 출력 / 커스텀 성적서 양식 제작·지정
  [자재]  자재 열람 / 자재 등록·수정·삭제 / 자재 일괄 등록
  [마스터] 계측기 관리 / 업체 관리
  [관리]  계정 관리 / 이메일(SMTP) 설정 / 활동 로그 열람

  * "검사 입력"만 있으면 본인이 입력한 성적서만 수정할 수 있고, "타인 성적서도 수정"이
    있어야 남이 입력한 것도 고칠 수 있습니다.
  * "부적합 통보서 작성"은 검사자, "확인·발송"은 관리자가 갖는 식으로 나눠서 줄 수 있습니다.
  * "계정 관리" 권한이 있는 계정은 10분 동안 화면을 안 만지면 자동 로그아웃됩니다(보안 목적).

"계정 관리" 권한이 없는 계정은 하루(24시간) 동안 로그인이 유지되니 태블릿마다
매번 로그인할 필요는 없습니다(계정관리 권한이 있는 계정만 10분 무동작 자동
로그아웃이 우선 적용됩니다).

비밀번호는 평문으로 저장됩니다(내부 전용 시스템 특성상). "계정 관리" 화면에서
계정관리 권한을 가진 사람이 언제든 각 계정의 현재 비밀번호를 확인·초기화할 수
있습니다. 단, 본인 계정 비밀번호는 화면에서 가려집니다(다른 관리자가 봐야 함).

[메뉴 구성]
상단 메뉴는 접속 계정의 권한에 따라 필요한 것만 보입니다:
  홈 / 📦 입고 / 🔍 검사(검사 입력·검사 이력·불량 이력·부적합 통보서·반품 처리) /
  ✅ 승인 / 🖨️ 출력(출력 대기·출력 기록·커스텀 성적서 양식) / 📊 품질 현황(현황 대시보드·불량 이력·업체 품질 성적표) / 📋 자재(자재 관리·자재 개별 등록·자재 일괄 등록·조립품 관리·업체 관리·4M 변경점) /
  ⚙️ 설정(계측기 관리·계정 관리·이메일 설정·활동 로그·데이터 점검)
※ 예전 용어 "규격"은 "자재"로 바뀌었습니다. 계측기 관리는 "설정"에 있습니다.

[계측기 유효기간 자동 연동]
검사 입력 화면에서 항목별 계측기 유효기간을 매번 손으로 적지 않아도 되게 만들었습니다.

  준비(한 번만):
  1) 설정 → 계측기 관리 로 들어갑니다.
  2) "측정방식에서 종류 불러오기" 버튼을 누르면, 자재에 적혀 있는 측정 방식
     (버니어캘리퍼스, 멀티테스터, 도금두께측정기 등)이 계측기 종류로 한 번에
     등록됩니다. (육안·외관·전수는 계측기가 아니라서 빠집니다.)
  3) 등록된 각 계측기의 "만료일(교정 유효기간)"을 채워 넣습니다.

  이렇게 해두면, 검사 입력 화면에서 각 항목의 측정 방식과 이름이 같은 계측기가
  자동으로 선택되고 유효기간이 함께 채워집니다. 띄어쓰기는 무시하고 맞춰줍니다
  (예: "도장두께측정기" = "도장 두께 측정기"). 목록에 없거나 이름이 다르면
  "직접 입력"으로 두고 날짜를 손으로 넣으면 됩니다.

  ※ 마이크로미터처럼 외경/내경을 따로 관리하는 계측기는 이름을 다르게 등록해
    두면(예: "외경 마이크로미터", "내경 마이크로미터") 자동으로 섞이지 않고,
    검사 시 검사자가 맞는 것을 고르면 됩니다.

  또한 자재 등록(자재 개별 등록 / 자재 상세)에서 "검사방법(측정 방식)" 칸은
  이제 등록된 계측기 목록이 드롭다운으로 뜹니다. 목록에 없는 방식은 그대로
  직접 입력할 수 있습니다.

[입고 리스트 등록 방법]
한 번 들어온 납품(같은 업체·입고날짜)에는 여러 자재가 섞여 있으므로,
공통 정보는 위에서 한 번만 입력하고 자재는 아래 표에 여러 줄로 넣습니다.
  1) 위쪽에 납품업체 / 입고날짜를 한 번 입력합니다(입고날짜는 오늘로 미리 채워짐).
  2) 아래 표에 자재를 줄마다 입력합니다: 발주번호 / 자재번호 / (제품명 자동) / 입고수량.
     - 발주번호는 자재마다 다를 수 있어서 공통이 아니라 "줄마다" 입력합니다.
     - "자재번호" 칸에 엑셀에서 자재번호를 세로로 복사해 붙여넣으면 여러 줄이 한 번에 채워집니다.
  3) 자재번호를 넣으면 그 자재에 등록된 "제품명"이 자동으로 표시됩니다.
     - 아직 자재 등록이 안 된 번호는 "미등록 자재"로 빨갛게 표시되지만, 입고 등록은 그대로 됩니다.
       (나중에 자재를 등록하면 제품명이 자동으로 채워집니다.)
  4) 같은 값을 여러 줄에 넣을 때: 셀을 마우스로 드래그해 범위를 잡은 뒤 "선택 영역 채우기"를
     누르면 선택 범위의 맨 위 값이 아래로 채워집니다(엑셀 채우기와 같음).
     예) 발주번호 첫 줄에 값을 넣고 그 열을 아래로 드래그 → "선택 영역 채우기" → 전부 같은 발주번호.
  ※ 제품명은 더 이상 직접 입력하지 않습니다 — 자재부서 요청서마다 이름이 달라지는 문제를 막기 위해,
    시스템에 등록된 자재명만 씁니다.
  ※ 같은 자재번호를 여러 줄에 넣으면(발주번호만 다르고 자재는 같은 경우) 자동으로 한 줄로
    합쳐집니다 — 입고수량은 더해지고, 발주번호는 줄이 나뉘어서 전부 표시됩니다.
    (한 번에 여러 발주가 같이 들어와서 한 배치로 검사하는 경우를 위한 기능입니다.
    이미 "대기" 상태로 등록돼 있던 이전 건과는 합쳐지지 않고, 이번에 붙여넣은 표 안에서만 합쳐집니다.)

[조립품 입고 - 파츠 자동 펼치기]
조립품(MA 등)은 파츠 번호 하나만 입력해도 나머지 파츠까지 자동으로 입고 리스트에 들어갑니다.
  - 입고 화면 아래 "조립품이면 구성 파츠까지 자동으로 펼치기" 체크박스로 켜고 끕니다.
  - 조립품 전체가 들어온 경우 → 체크 켜기 (파츠 전체가 한 번에 등록됨)
  - 파츠 하나만 스페어로 받은 경우 → 체크 끄기 (입력한 자재번호만 등록됨)
어떤 조립품에 어떤 파츠가 들어가는지는 "자재 → 조립품 관리"에서 직접 등록·수정합니다.
MA 말고 다른 조립품도 여기서 새로 만들 수 있습니다(파츠 번호를 한 줄에 하나씩 붙여넣기).

[최종결정권자 지정 - 중요]
승인·특채·불합격 확정, 그리고 부적합 통보서 확인은 "최종결정권자"로 지정된 사람만
할 수 있고, 전부 서명이 반드시 있어야 처리됩니다. (반려=재검사 요청 만 서명 없이 가능)
부적합 통보서는 협력사로 발송되는 문서라, 확인할 때 한 서명이 통보서 하단
"최종결정권자 승인" 칸에 그대로 찍혀서 나갑니다.
  - 지정 방법: 설정 → 계정 관리 → 해당 계정 클릭 → 권한 설정 아래
               "⭐ 최종결정권자" 체크 → 권한 저장
  - 최대 2명까지만 지정할 수 있습니다. 3번째를 체크하려면 먼저 다른 사람 체크를 풀어주세요.
  - "승인" 권한이 없는 계정은 최종결정권자로 지정할 수 없습니다.
    (이미 지정된 사람의 승인 권한을 빼면 최종결정권자 지정도 자동으로 풀립니다)
  - 아직 아무도 지정하지 않은 상태에서는 "승인" 권한만 있으면 승인할 수 있습니다.
    한 명이라도 지정하는 순간부터 최종결정권자만 승인할 수 있게 바뀝니다.

[금일 현황 - 아침에 여는 화면]
상단 "📅 금일 현황"을 누르면 오늘 뭘 해야 하는지 한 화면에 나옵니다.
  - 단계별로 밀린 일: 검사 대기 / 승인 대기 / 출력 대기 / 반려 (누르면 해당 화면으로 이동)
  - 오늘 실적: 입고·검사 건수와 수량, 검사 진행률, 오늘 내린 결정(합격/특채/불합격)
  - 지금 손대야 할 일: 재검사 필요 / 통보서 작성·확인·발송 필요 (누르면 바로 그 화면으로)
  - 오늘 검사자별 처리량 (건수·수량·불량·소요시간)
날짜를 바꾸면 지난 날짜도 볼 수 있습니다.

[화면에 있는 물음표(?) 아이콘]
AQL, PPM, Cpk 같은 용어 옆의 물음표에 마우스를 올리면 설명이 뜹니다(엑셀 메모처럼).
클릭하면 설명이 고정되고, ✕를 누르거나 다른 곳을 클릭하면 닫힙니다.

[품질 현황 대시보드]
"📊 품질 현황 → 현황 대시보드"에서 검사·불량 실적을 한 화면에서 봅니다.
  - 기간 단위: 일간 / 주간 / 월간 / 분기 / 반기 / 연간
  - 필터: 업체, 발주번호(로트), 자재번호·제품명, 시작일~종료일
  - 표나 행을 누르면 팝업으로 성적서 / 도면 / 부적합 통보서 / 공정능력을 바로 봅니다

불량률은 "수량 기준"입니다:
    불량률 = 불합격 확정 수량 ÷ 판정 확정 수량 × 100
    PPM = 불량률 × 10,000
  ※ 승인 대기·반려 건은 아직 결과가 아니므로 계산에서 빠집니다("미결"로 따로 표시)
  ※ 특채는 불량률에 안 들어가고 "규격이탈률"로 따로 봅니다

내보내기 3가지:
  📄 JSON - 발표자료 만들 때 (기간·필터·불량률 기준이 같이 들어있어 이것만 넘기면 됨)
  📊 엑셀 - 직접 피벗 돌리거나 본사 양식에 붙일 때 (시트별로 요약/기간별/업체별/자재별 등)
  🖨️ 인쇄 - 그대로 결재 올릴 때

[공정능력 (Cpk)]
대시보드 자재별 표에서 행을 누르면 공정능력을 봅니다.
규격 대비 실제 측정값이 얼마나 여유 있게 들어오는지 보는 지표로, 자동차 부품은 보통
Cpk 1.33 이상을 요구합니다.
  우수 1.67 이상 / 양호 1.33 이상 / 주의 1.0 이상 / 부족 1.0 미만
  ※ "표본부족"은 측정 데이터가 아직 적다는 뜻이고, "산포없음"은 측정값이 전부 같아서
    계측기 분해능을 확인해볼 필요가 있다는 뜻입니다.

[업체 품질 성적표]
"📊 품질 현황 → 업체 품질 성적표"에서 업체별 월간 성적을 뽑아 협력사에 보냅니다.
부적합 통보서가 사고 난 뒤 나가는 것이라면, 이건 매달 정기적으로 나가서 업체가
스스로 관리하게 만드는 용도입니다.
  1. 업체와 대상 월을 골라 "생성" (누구나 가능)
  2. 최종결정권자가 서명하고 "승인"
  3. 승인된 것만 "발송" 가능
  ※ 승인·발송된 성적표는 기록 보존을 위해 다시 만들 수 없습니다(초안만 갱신 가능).

[검사 입력 자동저장]
검사 입력 화면은 값을 넣을 때마다 자동으로 서버에 저장됩니다. 별도 저장 버튼은 없습니다.
  - 화면 오른쪽에 "✓ 자동 저장됨" 표시가 뜹니다
  - 태블릿 배터리가 나가거나 다른 기기로 옮겨가도 이어서 입력할 수 있습니다
  - 인터넷이 끊기면 "⚠ 서버 저장 실패 (이 기기에는 보관됨)"이 뜨고, 그 기기에서는 계속 입력됩니다
  - 성적서를 제출하면 임시저장은 자동으로 지워집니다

[성적서 AQL 표기]
성적서 AQL 칸은 두 줄로 나갑니다:  "4" / "샘플 5개/무결점"
이 시스템은 샘플 중 하나라도 규격을 벗어나면 불합격입니다(무결점 기준).
본사 양식이라 AQL 표기는 그대로 두고, 실제 판정 근거를 같이 적는 방식입니다.

[커스텀 성적서 양식 - 직접 디자인한 성적서]
기본(본사) 양식 대신, 자재별로 직접 만든 성적서 양식을 쓸 수 있습니다.
"🖨️ 출력 → 커스텀 성적서 양식"에서 만듭니다.

  1) "새 양식 만들기"로 이름을 정하면 디자이너 화면이 열립니다.
  2) 왼쪽 팔레트의 요소(제목 텍스트·회사 로고·구분선·서명란·데이터 필드·검사항목표)를
     가운데 종이로 끌어다 놓습니다. "격자에 맞추기"를 켜면 반듯하게, 끄면 자유롭게 놓입니다.
  3) 요소를 클릭하면 오른쪽에서 글자 크기·굵기·정렬·위치·크기를 고칠 수 있습니다.
     지우려면 요소를 고른 뒤 Delete 키 또는 "이 요소 삭제".
  4) "데이터 필드"(자재번호·제품명·업체명·검사일·검사자·발주번호·도면번호·입고수량)는
     디자이너에선 예시값으로 보이지만, 실제 출력 때 그 성적서의 진짜 값이 채워집니다.
  5) "검사항목표"는 항목 수만큼 세로로 자동으로 늘어납니다(표 아래 요소는 그만큼 밀려 내려감).
     표를 클릭하면 오른쪽에서 표 자체를 자세히 꾸밀 수 있습니다:
       · 열(칸) 구성 — 열을 추가·삭제하고, 순서(▲▼)와 너비를 바꾸고, 머리글 이름과
         정렬을 정하고, 그 칸에 어떤 값을 채울지(항목/규격/검사방법/측정값/판정/빈칸)를 고릅니다.
       · 측정값 표기 — "한 칸에 모두" 또는 "회차별로 나누기(1회·2회·3회)" 중에서 고릅니다.
         회차별로 나누면 측정값을 콤마로 구분해 각 칸에 나눠 담고, 그 위에 "측정값" 머리행이
         자동으로 병합되어 덮입니다.
       · 머리행 묶기(병합) — 여러 열을 골라 하나의 상위 머리행으로 묶습니다
         (예: 1·2·3회 위에 "측정값"). 표는 이때 머리행이 두 줄이 됩니다.
       · 요약행 — 표 맨 아래에 "종합판정"·"비고" 같은 줄을 추가합니다. 값은 검사 데이터에서
         자동으로 가져오거나(종합판정·업체명 등), 고정 문구를 직접 적을 수 있습니다.
     ※ 아무것도 안 건드리면 기존 5칸 표(항목/규격/측정값/판정/비고)가 그대로 나옵니다.
  6) "💾 저장" 후 "📄 PDF 미리보기"로 실제 나올 모습을 확인하세요.
  7) "🔗 자재에 지정"에서 이 양식으로 출력할 자재를 고릅니다.
     지정한 자재는 앞으로 이 양식으로, 지정 안 한 자재는 기존 기본 양식 그대로 나갑니다.

  ※ 커스텀 양식으로 나가는 성적서에는 기준서 페이지가 붙지 않습니다(양식을 직접 만든 것이므로).
    출력할 때 "도면"만 앞에 붙일 수 있습니다.
  ※ 양식을 삭제하면 그 양식을 쓰던 자재는 자동으로 기본 양식으로 돌아갑니다.
  ※ 디자이너 화면은 마우스·키보드를 움직이는 동안 로그인이 자동으로 유지됩니다(가만히
    오래 두면 계정관리 권한 계정은 10분 뒤 로그아웃). 만약 자리를 오래 비워 로그인이
    풀리면 저장할 때 화면 위에 빨간 띠로 "다시 로그인하라"고 안내가 뜹니다 — 안내대로
    새 탭에서 다시 로그인한 뒤 이 화면으로 돌아와 저장을 다시 누르면 됩니다(작업 내용은
    그대로 남아 있습니다).

[승인·불합격 결정이 막히는 경우]
다음 중 하나라도 해당하면 승인·특채·불합격 확정이 되지 않습니다:
  - 규격(하한·상한)이 비어 있는 항목이 있음 → 자재 규격을 먼저 채우고 재검사
  - 측정값이 비어 있는 항목이 있음 → 검사를 먼저 마무리
  - 전 항목 합격인데 "특채"를 누름 → 특채는 규격을 벗어난 것을 예외적으로 쓸 때만 씁니다
  - 불합격 확정인데 사유를 안 적음 → 협력사 통보의 근거가 되므로 사유가 필수입니다
※ 규격이 비어 있으면 "불합격"도 막힙니다. 우리 데이터가 빠진 것을 협력사 잘못으로
   통보하면 안 되기 때문입니다.

[한 입고 건에는 성적서 하나]
이미 검사한 입고 건에 다시 들어가면 기존 성적서로 이동합니다.
내용을 고치려면 성적서에서 "수정", 다시 검사하려면 "재검사"를 눌러주세요.
  ※ 예전에는 등록 버튼을 여러 번 누르면 성적서가 여러 개 생겨서, 대시보드에서
    같은 로트 수량이 중복으로 잡히는 문제가 있었습니다.

[승인을 회수하면]
승인·반려·불합격 결정을 회수하면 승인자 서명과 위변조 검증 기준값도 함께 지워집니다.
다시 승인하면 그 시점 기준으로 새로 봉인됩니다.
  ※ 연결된 부적합 통보서나 반품 기록이 있으면 회수할 수 없습니다.

[성적서 위변조 검증]
승인된 성적서는 승인 시점의 내용이 자동으로 봉인됩니다.
성적서 상세를 열면 아래에 표시됩니다:
  🔒 무결성 확인됨       - 승인 당시와 같음
  🚨 내용이 바뀌었어      - 승인 후 데이터가 변경됨 (원인 확인 필요)
  🚨 PDF 파일이 달라      - 발행된 파일이 교체됨
※ 이 기능이 생기기 전(2026-08-23 이전)에 승인된 성적서는 기준값이 없어 검증되지 않습니다.

[4M 변경점]
"자재 → 4M 변경점"에서 협력사가 사람/설비/자재/방법을 바꾼 시점을 기록합니다.
  - 기록해두면 그 업체 자재를 검사할 때 최근 90일 내 변경이 있으면 검사 화면에 경고가 뜹니다
  - 나중에 변경 전후 불량률을 비교하는 근거가 됩니다 (IATF 변경점 관리)
  - 자재번호를 비워두면 그 업체 전체에 해당하는 변경으로 기록됩니다

[데이터 점검 - 관리자 전용]
"설정 → 🩺 데이터 점검"에서 검사·성적서를 망가뜨릴 수 있는 데이터 문제를 한눈에 봅니다.
  🔴 시급  - 규격(하한·상한)이 비어 있는 항목, 규격이 아예 없는 자재,
             조립품 파츠인데 자재로 등록 안 된 번호  → 이건 검사가 아예 막힙니다
  🟠 확인  - 자재번호 자리에 한글 품명이나 "-" 같은 값이 들어간 자재
  🔵 참고  - 도면 미연결, 규격 표기가 중복된 항목, 중요항목(*)과 AQL 불일치
이 메뉴는 "계정 관리" 권한이 있는 사람만 볼 수 있습니다.

[규격이 비어 있는 항목은 어떻게 되나요]
하한·상한이 둘 다 비어 있으면 판정 기준이 없는 것이므로 "규격미입력"으로 표시됩니다.
  - 합격도 불합격도 아닙니다 (협력사에 부적합 통보서가 잘못 나가지 않게 하기 위함)
  - 성적서 전체는 "검토필요"가 되고, 승인 버튼이 막힙니다
  - 검사 입력 화면에서도 측정 전에 빨간 경고가 뜹니다
해결: "자재 관리"에서 그 항목의 하한/상한을 채우거나, 숫자로 재는 항목이 아니면
      판정 방식을 "적합/부적합"으로 바꿔주세요.

[검사방식(계측기)이 비어 있는 자재 찾기]
"자재 관리" 화면의 검색 기준에서 "검사방식 미입력"을 고르면(검색어는 비워도 됩니다)
검사방식이 안 적힌 항목을 가진 자재만 모아서 보여줍니다. 하나씩 열어서 채워주세요.
(외관·육안처럼 계측기가 필요 없는 항목도 함께 나올 수 있습니다.)

[목록에서 클릭하면 팝업으로 열기]
자재 관리 / 검사 대기 / 출력 대기 목록에는 "행을 클릭하면 팝업으로 열기" 체크박스가
있습니다. 켜두면 목록에서 한 줄을 눌렀을 때 페이지가 넘어가지 않고 그 자리에서
상세 화면이 팝업으로 뜹니다(팝업 안에서 수정·저장도 됩니다). 팝업을 닫으면 방금
바꾼 내용이 목록에도 반영됩니다. 이 설정은 기기별로 기억되니 한 번만 켜두면 됩니다.
끄면 예전처럼 페이지 이동으로 열립니다.

[활동 로그 / 자동 백업]
성적서 등록·수정, 자재 등록·수정·삭제, 입고 리스트 등록, 승인/반려, 계정 관리 등
데이터가 새로 생기거나 바뀔 때마다 자동으로:
  1. "설정 → 활동 로그"(로그 권한 보유자)에서 조회 가능한 기록이 남고
  2. backups/ 폴더에 그 시점의 iqc.db 전체가 통째로 복사·저장되고
  3. backups/README.txt에 사람이 읽을 수 있는 상세 로그 한 줄이 추가됩니다
     (예: "[2026-08-19 19:06:56] 사용자: admin(최고관리자) | 액션: 입고 리스트
      등록 | 대상: intake | 상세: 1건(602106P103) | 백업파일: iqc_..._2.db")
문제가 생기면 backups/README.txt에서 원인이 된 시점을 찾고, 그 옆에 적힌
백업파일(iqc_YYYYMMDD_HHMMSS_번호.db)을 iqc.db로 이름 바꿔서 복원하면 됩니다.

백업은 자동으로 정리되니 직접 지우실 필요 없습니다:
  - 최근 30개는 무조건 보관
  - 그보다 오래된 것은 하루에 1개씩만 남김
  - 90일이 지난 것은 삭제
  ※ 직접 만드신 백업(파일명이 iqc_before_... 처럼 날짜 형식이 아닌 것)은
    자동 정리 대상이 아니라 그대로 보존됩니다.

[새 자재(규격) 추가하는 법 - 웹에서]
"자재" 메뉴에서 코드 없이 웹으로 등록합니다:
  - 자재 개별 등록: 항목/규격을 한 자재씩 직접 입력(측정조건 팝업, 이전 자재 불러오기 지원)
  - 자재 일괄 등록: 빈 성적서 양식(.xlsx) 파일들을 한 번에 올리면 자재번호·자재명·항목별
    규격을 자동으로 찾아 등록(같은 자재번호를 다시 올리면 통째로 교체됨)
등록/수정에는 "자재 등록·수정·삭제" 권한이, 일괄 등록에는 "자재 일괄 등록" 권한이 필요합니다.

[폴더 구성]
  app.py            - 서버 본체(라우트·판정·권한)
  database.py       - DB 관리(SQLite)
  report_builder.py - 성적서·기준서 xlsx/PDF 생성
  spec_import.py     - 자재 일괄 등록 파서
  template_form.xlsx - 빈 성적서 양식
  standard_template.xlsx - 기준서 양식
  templates/         - 웹 화면들
  iqc.db            - (실행 후 자동 생성) 데이터베이스
  성적서 발행/       - (실행 후 자동 생성) 완성된 성적서 저장 위치 — 생성날짜별 폴더 안에
                      "YYMMDD_업체명_자재번호_제품명.pdf/.xlsx" 형식으로 저장됨

※ Render 서버는 태블릿/PC에서 이 폴더에 직접 접근할 수 없으므로("성적서 발행/"은 서버
  안에만 있음), "🖨️ 출력" 결과 화면과 "출력 기록" 상세 화면에 "⬇ 다운로드" 버튼이 있습니다.
  이걸 누르면 그 PDF가 지금 쓰는 기기(태블릿/PC)로 바로 저장됩니다. 여러 건을 한 번에 출력한
  경우엔 "📦 전체 zip으로 한 번에 다운로드" 버튼으로 한 번에 받을 수 있습니다.
