# QMS 개선 백로그

2026-09-17 "품질최고경영자+데이터관리 전문가" 관점 QMS 종합진단(4트랙 병렬 fork 감사
→ 인용 17건 재검증 → 실제 로그인·대시보드 라이브 검증)에서 나온 개선 항목을 추적하는
문서다. 전체 진단 리포트(총평·영역별 점수·레이더차트·실행계획 2건 포함)는 Artifact로
게시돼 있다: https://claude.ai/code/artifact/98989391-62ce-4012-9121-0227075e5089

**사용 규칙**: 항목을 구현하면 체크박스를 채우고 `완료 YYYY-MM-DD · 커밋 <hash>`를
그 줄에 덧붙인다. 새 개선사항이 다른 작업 중에 발견되면(코드 리뷰, quality-watcher,
사용자 피드백 등) 여기 해당 우선순위 구간에 추가해서 계속 누적 관리한다. 삭제하지
말고 완료 표시만 남긴다 — 뭐가 언제 왜 고쳐졌는지 이력 자체가 가치다.
