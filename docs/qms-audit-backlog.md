  결과 전부 컬럼명이 코드에 고정돼 있고 값은 `?` 파라미터 바인딩이라 **현재는 실제
  인젝션 취약점이 아님**(2026-09-17 직접 대조 확인). 다만 테스트·정적분석 도구가
  없어서, 나중에 누군가 실수로 이 패턴에 사용자 입력을 직접 끼워넣어도 잡아줄
  안전망이 없다 — 패턴 자체를 없애는 것보다 이 리스크를 인지하고 있는 게 중요.
